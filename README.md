# Leek Wars Tools

Forked from [leek-wars](https://github.com/leek-wars/leek-wars)

The only change from the official version is that it is served by a custom local API server

Used for the fight generation for [leek-wars-tools](https://github.com/Bux42/Leekwars-Tools) API


## How to run

Install the packages

```
npm i
```

Build the project

```
npm run build
```

Run the frontend from built sources (faster)

```
npm run preview
```
